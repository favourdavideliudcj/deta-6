Authentication

Authenticate all REST API requests using Bearer tokens in the Authorization header. Never expose secret keys in client-side bundles.

bash / curl 
curl -X GET https://vektor.dev \
  -H "Authorization: Bearer vk_live_98a76b54c321" \
  -H "Content-Type: application/json"

Webhook Events

Subscribe to real-time asynchronous events such as deployment.succeeded or invoice.paid with HMAC-SHA256 signature verification.

javascript 
import { verifySignature } from '@vektor/sdk';

export async function POST(req) {
  const signature = req.headers.get('x-vektor-sig');
  const isValid = verifySignature(await req.text(), signature, process.env.WEBHOOK_SECRET);
  return new Response(isValid ? 'OK' : 'Invalid', { status: isValid ? 200 : 401 });
}

Rate Limits

Standard workspaces allow up to 1,200 requests per minute. Inspect the X-RateLimit-Remaining response header to throttle background workers gracefully.
